## About This Portfolio

This site is both an archive and an argument: AI can be dangerous because it flattens identity into statistical patterns — but my making process showed me that human creativity and judgment are irreplaceable.

Across twelve makes, I worked with ChatGPT, DALL·E, Canva, and other tools to create artifacts that explore AI through practice, not just theory. Each make includes the artifact, a 150–300 word reflection, and a full attribution log.
